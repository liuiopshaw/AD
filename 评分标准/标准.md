## 调整后的六维评估框架（突出纳米制剂优势）

| 维度 | 权重 | 核心问题 | 调整说明 |

|:---|:---:|:---|:---|

| **0. AD 相关性（门控维度）** | 门控 | 该治疗剂与 AD 治疗是否真正相关？ | **新增：不参与加权，综合分 = 五维加权分 × (AD相关性 ÷ 10)** |

| **1. 靶组织递送效率** | 30% | 该治疗剂能否有效到达其作用部位？ | 保留，调整评分侧重“可设计性” |

| **2. 多靶点协同潜力** | 15% | 该治疗剂能否同时干预AD的多个病理环节？ | 保留 |

| **3. 效应持续时间** | 10% | 该治疗剂产生的效应是瞬时的还是可持续的？ | 保留 |

| **4. 生产质控与精准调控能力** | 25% | 该治疗剂的制备是否可控、可规模化、可精准调控？ | **原“制剂稳定性与可及性”重构** |

| **5. 生物安全性** | 20% | 在有效剂量下的风险-收益比如何？ | 保留 |

> **综合分公式（加性版）**：综合分 = 维度1×30% + 维度2×15% + 维度3×10% + 维度4×25% + 维度5×20%。
> 维度0「AD 相关性」仅作记录与参考，不参与综合分计算。（另备有硬门控 ×(维度0÷10) 与软门控 ×(0.5+0.5×维度0÷10) 两个变体，实验时通过参数选择。）

### 维度零：AD 相关性（门控维度，不参与加权）

**核心问题**：该治疗剂与 AD 治疗是否真正相关？

| 分数 | 标准 |

|:---|:---|

| 9–10 | 已获批 AD 适应症，或在 AD 患者中有确证疗效 |

| 7–8 | 针对 AD 的临床阶段候选药物（II/III 期），或有强临床前 AD 证据 |

| 5–6 | 有临床前 AD 证据，或机制上明确针对 AD 病理环节 |

| 3–4 | 仅间接/推测与 AD 相关（如泛抗氧化、泛抗炎），无 AD 特异性证据 |

| 1–2 | 与 AD 无关的无关药物/化合物 |

> **示例**：

> - **多奈哌齐（Donepezil）**：已获批 AD 一线治疗 → **9-10分**

> - **抗 Aβ 单抗（临床阶段）**：针对 AD 核心病理的临床候选 → **7-8分**

> - **维生素 C 等无关药物**：泛抗氧化，无 AD 特异性证据 → **1-2分**

维度四“生产质控与精准调控能力”

### 原维度的问题

“制剂稳定性与可及性”将FMT（已有临床应用）与小分子药物（成熟工艺）置于过高位置，而纳米制剂虽然合成可控性强，但因“尚未大规模临床应用”而在该维度失分。

### 重构后的评分标准

**核心问题**：该治疗剂的制备是否可控、可规模化、可精准调控其组成和剂量？

| 分数 | 标准 |

|:---|:---|

| 9–10 | 化学组成明确、合成路线可控、批次间一致性高、可精确调控剂量、易于规模化生产 |

| 7–8 | 组成较明确、合成可控、可规模化生产 |

| 5–6 | 组成复杂但可控、规模化存在一定挑战 |

| 3–4 | 组成不明确或高度依赖供体/生物来源、批次差异大、难以精确调控 |

| 1–2 | 不可控、无法规模化 |

> **各类治疗剂的预期表现**：

> - **纳米制剂**：化学组成明确（如CD-Cu@Qe具有精确的分子式），合成路线可控，批次一致性高，可精确调控剂量和表面修饰 → **9分**

> - **小分子药物**：化学合成成熟，组成明确，可控性高 → **9分**

> - **粪菌移植（FMT）**：组成高度依赖于供体菌群，批次差异大，难以标准化和精确调控 → **3–4分**

> - **生物制剂（抗体/多肽）**：生产复杂但可控，批次一致性较高 → **7–8分**

### 维度一：靶组织递送效率（权重：30%）

**核心问题**：该治疗剂能否有效到达其作用部位？

| 分数 | 标准 |

|:---|:---|

| 9–10 | 能高效到达靶组织，给药途径明确，且可通过设计优化递送效率 |

| 7–8 | 能有效到达靶组织，给药途径明确 |

| 5–6 | 能部分到达靶组织，但存在一定递送瓶颈 |

| 3–4 | 面临重大递送挑战 |

| 1–2 | 尚无可行递送策略 |

> **纳米制剂**：可通过表面修饰靶向特定组织，腹腔注射可绕开胃肠道屏障 → **8–9分**

> **FMT**：直接通过口服胶囊或灌肠递送，但定植效率因人而异 → **6–7分**

### 维度二：多靶点协同潜力（权重：15%）

**核心问题**：该治疗剂能否同时干预AD的多个病理环节？

| 分数 | 标准 |

|:---|:---|

| 9–10 | 能同时干预≥3个AD核心病理环节，且有协同效应证据 |

| 7–8 | 能同时干预2个AD核心病理环节 |

| 5–6 | 主要针对1个病理环节 |

| 3–4 | 仅针对单一靶点 |

| 1–2 | 靶点不明确 |

> **纳米制剂**：可作为多功能平台，同时实现抗菌、抗氧化、抗炎、调节代谢 → **8–9分**

> **FMT**：可恢复菌群多样性，影响代谢和免疫，间接影响多个AD病理环节 → **7–8分**

### 维度三：效应持续时间（权重：10%）

**核心问题**：该治疗剂产生的效应是瞬时的还是可持续的？

| 分数 | 标准 |

|:---|:---|

| 9–10 | 单次/短期干预可产生长期生物学效应 |

| 7–8 | 效应可持续数周至数月 |

| 5–6 | 效应持续时间有限 |

| 3–4 | 效应短暂，停药后快速消退 |

| 1–2 | 无持久效应证据 |

> **纳米制剂**：菌群生态重塑后可自我维持 → **7–8分**

> **FMT**：供体菌群的定植和维持取决于受体肠道生态位，部分患者可长期获益 → **7分**

### 维度四：生产质控与精准调控能力（权重：25%）

**核心问题**：该治疗剂的制备是否可控、可规模化、可精准调控其组成和剂量？

| 分数 | 标准 |

|:---|:---|

| 9–10 | 化学组成明确、合成可控、批次一致、剂量可精确调控、易于规模化 |

| 7–8 | 组成较明确、可控、可规模化 |

| 5–6 | 组成复杂但可控、规模化存在挑战 |

| 3–4 | 组成不明确、批次差异大、难以精确调控 |

| 1–2 | 不可控、无法规模化 |

> **纳米制剂**：组成明确，合成可控，剂量可精确调控 → **9分**

> **小分子药物**：组成明确，合成成熟 → **9分**

> **FMT**：供体依赖性，批次差异大，难以标准化 → **3–4分**

### 维度五：生物安全性（权重：20%）

**核心问题**：在有效剂量下的风险-收益比如何？

| 分数 | 标准 |

|:---|:---|

| 9–10 | 副作用轻微可控 |

| 7–8 | 副作用中等，可监测管理 |

| 5–6 | 存在一定安全性顾虑 |

| 3–4 | 存在明确的安全性风险 |

| 1–2 | 严重安全性问题 |

> **纳米制剂**：铜为必需微量元素，超小尺寸利于清除，生物相容性良好 → **7–8分**

> **FMT**：存在感染风险、耐药菌传播等潜在问题，但总体可控 → **6–7分**
