### 1. 选择性抗菌机理（核心新增）
解释为什么该材料对致病菌和益生菌产生差异性活性：

- **细胞壁/膜结构差异：**
  致病菌与益生菌细胞壁/膜的本质差异（G+/G-壁厚度、脂磷壁酸含量、表面电荷密度）
  
- **材料表面修饰的选择性亲和：**
  材料表面修饰（如环糊精包覆、电荷调控）对不同细菌的选择性亲和力差异

- **致病菌特异性代谢途径靶向：**
  致病菌特异性代谢途径被材料靶向干扰（如铁摄取系统、群体感应系统）

- **益生菌抗氧化防御：**
  益生菌的抗氧化防御系统（SOD、CAT内源酶）对材料产生的ROS有更高耐受阈值

- **膜电位差异：**
  致病菌膜电位更高，更容易被阳离子纳米材料静电吸附和破坏

- **体内外一致性：**
  体内与体外选择性一致性的机制解释

### 2. 类酶活性机理
- 活性位点化学环境（配位构型、氧化态）
- 底物结合模式（与天然CAT/SOD/NADH氧化酶的类比）
- 电子转移路径
- 对AD治疗有益的特殊类酶功能：
  CAT-like + SOD-like 级联清除ROS → 减轻神经氧化应激
  NADH oxidase-like 提升NAD⁺水平 → 保护神经元

### 3. 菌群调控→AD 治疗路径（核心新增）

- **抑制致病菌→减轻神经炎症：**
  抑制肠道致病菌 → 减少LPS入血 → 减轻系统性炎症 →
  保护血脑屏障完整性 → 减少神经炎症和Aβ沉积

- **保护SCFAs菌群→维持肠道屏障：**
  保护/富集产短链脂肪酸（SCFAs）菌群 → 丁酸、丙酸维持肠道屏障 →
  减少"肠漏" → SCFAs通过迷走神经/体液途径入脑 → 调节小胶质细胞极化

- **菌群胆汁酸代谢→减少Aβ：**
  调节菌群胆汁酸代谢 → 影响FXR/TGR5信号 → 减少Aβ产生

- **色氨酸代谢→神经保护：**
  降低肠道致病菌的色氨酸代谢 → 减少吲哚类神经毒素 → 保护海马神经元
